## Art

**Card, creature and Opponent art is original to this project** — flat vector SVG drawn against a
fixed six-colour palette. See `KinUI.md` under "Art" for the rules every asset follows.

## For whoever ships this

A release checklist for this file specifically:

1. Every third-party asset in the game appears above, by name and author.
2. The game-icons attribution line is visible **in the game or on its store page**, not only here.
3. Anything added after this was written has been added above. Assets arrive quietly; credits do not
   update themselves.
